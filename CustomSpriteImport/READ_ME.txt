=== Custom Sprite Import folder ===

Drop your own Pokemon / fusion sprite .png files in HERE, then in-game open:
    Options  ->  KIF Settings  ->  Import Custom Sprites

You no longer need to look up dex IDs or name the files by hand. The importer
lets you search each Pokemon by NAME (or dex number), and copies the file into
Graphics/Battlers with the correct  <head>/<head>.<body>.png  name in BOTH
fusion directions automatically.

- Fusion sprite: pick the file, choose "Fusion", then pick the two Pokemon.
- Base sprite:   pick the file, choose "Single Pokemon", then pick one Pokemon.

Files can be named anything (e.g. mySprite.png) - the importer handles the
final naming for you. After a successful import you can have the file removed
from this folder.
